# Meal App — screen mockups (static reference)

Plain-HTML copies of the Claude design-canvas mockups, for building the app with Claude Code.

- `index.html` — contact sheet showing all 8 screens together. Open this first.
- One file per screen: setup, recipes, confirm, plan, list, shop, receipt, spending.
- The main navigation and primary buttons link to each other, so you can click through.

These are a VISUAL + COPY spec, not app code. They use inline styles and plain HTML/CSS.
Build the real screens in React + Tailwind (matching Buoy's stack); treat these as the
target layout, copy, and color. Palette: ground #F3F1EC, ink #1A1714, primary green #0F7A5A,
amber #B07A12. Font: Inter.

Suggested use: drop this folder in the repo at `design/mockups/` and point Claude Code at it.
